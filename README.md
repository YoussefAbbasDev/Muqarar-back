# Muqarar · مُقرَّر

> كل مقرراتك وتنبيهاتك في مكان واحد.

موقع محلي بيعرض ملفات المقررات والتكليفات والاختبارات من منصة
`dtu.deltateach.com` بشكل مرتب، مع تنزيل الملفات محلياً ومعاينة PDF داخل الموقع.

## الهوية البصرية

| العنصر | القيمة |
|---|---|
| Ink Black | `#151515` |
| Cold White | `#F7F7F4` |
| Signal Orange | `#FF4A1C` |
| Stone Gray | `#6B665A` |
| Display | Playfair Display |
| Code / UI | PT Mono |
| Arabic headings | Alexandria |
| Arabic body | Lemonada |
| Accents | Marhey |

الواجهة بتستخدم حواف حادة، خطوط رفيعة، مساحات فاضية، ولمسات برتقالية محدودة.
اللوجو عبارة عن شرارة (sparkle) ثمانية الأطراف، وفيه مثلث برتقالي في الأركان
كعنصر توقيع. التوكنز والخطوط معرّفة في `web/src/index.css` و`web/index.html`.

> **مهم:** ده موقع محلي. السيرفر بيسمع على `127.0.0.1` بس، وكل مستخدم بيسجّل
> دخوله بحسابه من صفحة الإعدادات. ممنوع نشره على الإنترنت العام من غير طبقة
> مصادقة إضافية.

## المتطلبات

- Node.js 20 أو أحدث
- حساب الطالب على منصة DTU

## التشغيل

```bash
npm install
npm --prefix web install
npm run build
npm start
```

بعد التشغيل افتح: <http://127.0.0.1:3000>

أول مرة هتظهر شاشة تسجيل الدخول. اكتب بيانات حسابك على منصة DTU، والموقع هيعمل
أول مزامنة في الخلفية. بعد كده فيه مزامنة كل ساعة وزرار «تحديث دلوقتي» في
الشريط الجانبي. أول مزامنة ممكن تاخد دقيقة حسب عدد الملفات وحجمها.

### التطوير

شغّل الباك إند والفرونت في تيرمنالين:

```bash
node server.mjs
npm run dev:web
```

Vite بيحوّل طلبات `/api` للسيرفر على `127.0.0.1:3000`.

## تسجيل الدخول والإعدادات

- أول زيارة: تظهر شاشة إعداد أولي فيها اسم المستخدم وكلمة المرور.
- بعد الدخول: أيقونة الترس (⚙) في الشريط الجانبي بتفتح **الإعدادات**، ومنها
  تقدر تغيّر الحساب أو تسجّل الخروج.
- كل حساب ليه بياناته وملفاته المنفصلة في `data/accounts/<مفتاح الحساب>/`.
- بيانات الدخول بتتخزن في **ذاكرة السيرفر فقط**؛ مفيش كلمة مرور بتتحفظ على
  الديسك. لو السيرفر اتقفل، هتحتاج تسجّل الدخول تاني.
- ملف `.env` مش مستخدم في تسجيل الدخول. لو عندك ملف قديم فيه
  `DTU_USER` / `DTU_PASS`، تقدر تمسحه.
- مفيش أي بيانات دخول مكتوبة في الكود أو بتتطبع في اللوج.

## إزاي بيشتغل

- `client.mjs`: إنشاء axios instance + cookie jar، وتسجيل الدخول ببيانات
  الحساب اللي جاية من واجهة الموقع.
- `platform.mjs`: كل الـ parsers والـ selectors الخاصة بالمنصة (ملف واحد).
- `sync.mjs`: المزامنة، تنزيل الملفات، دمج التكليفات/الاختبارات، والكتابة
  الذرية على `data/accounts/<key>/data.json`.
- `server.mjs`: Express + جلسات في الذاكرة + cron كل ساعة، وبينشر على
  `127.0.0.1` فقط.
- `web/`: React + Vite + Tailwind، وناتج البناء في `public/`.

الملفات بتتخزن في `data/accounts/<key>/files/` باسم
`{أول 8 من الـ id}_{العنوان}{الامتداد}`. الملف بيتنزل على `.part` وبعدين
بيتعمله rename، فمفيش ملف ناقص بيتحسب منزّل.

### الـ API

| Endpoint | الوظيفة |
|---|---|
| `GET /api/session` | هل في جلسة مسجّلة + اسم الحساب |
| `POST /api/login` | التحقق من بيانات الحساب وبدء أول مزامنة |
| `POST /api/logout` | إنهاء الجلسة |
| `GET /api/data` | البيانات + حالة المزامنة |
| `POST /api/sync` | بدء مزامنة في الخلفية |
| `GET /api/files/:id/download` | تنزيل ملف بالاسم الأصلي وامتداده |
| `GET /api/files/:id/view` | معاينة PDF/صورة داخل الموقع |

كل مسارات `/api` ما عدا الدخول والجلسة محتاجة جلسة صالحة.

## الأمان

- السيرفر بيسمع على `127.0.0.1:3000` فقط.
- كلمات المرور في ذاكرة السيرفر فقط، والجلسة في cookie من نوع HttpOnly.
- كل حساب معزول في مجلد بيانات خاص به.
- مفيش أي POST مؤثر على حساب الطالب. الـ POSTs الوحيدة:
  تسجيل الدخول، `AvailableCourseHomework`، و`DisplayStudentExamList` (قراءة).
- مفيش لمس لفورم `GoToExam` ولا رفع حلول ولا تعديل بيانات الحساب.
- في تأخير 200–300ms بين كل طلب والتاني، والطلبات متسلسلة.
- أي token طويل بيتشال من رسائل الخطأ قبل طباعتها.

## لو المنصة غيّرت شكلها

كل الـ selectors في `platform.mjs`. لو selector مرجعش حاجة، المزامنة بترمي
رسالة واضحة وتظهر في `data.json` تحت `errors` وفي الشريط الجانبي، والبيانات
القديمة بتفضل زي ما هي. مفيش كتابة `data.json` جديد لو فشل تسجيل الدخول أو
فشلت قراءة كل المواد.

## ملاحظات

- التكليفات والاختبارات **تنبيهات فقط**؛ الموقع لا يسلّم ولا يفتح ولا يحل أي شيء.
- الاختبارات ملهاش موعد بدء في المنصة، فبيعرض موعد الانتهاء بس.
- التنبيه بيختفي تلقائياً بعد موعد انتهائه، وبيتلوّن أحمر لو باقي أقل من 24 ساعة،
  وبرتقالي لو أقل من 3 أيام.
- الملفات اللي بتتشال من المنصة بتفضل محفوظة عندنا ومعلّمة «اتشال من المنصة».
- زرار «عرض» بيظهر لملفات PDF والصور وبيعرضها داخل الموقع من غير تنزيل.
